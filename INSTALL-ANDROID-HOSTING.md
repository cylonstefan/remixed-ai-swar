# 📱 AI Swarm OS v3.2 - Android & Hosting Deployment Guide

This guide covers how to deploy AI Swarm OS to mobile devices (as MDM nodes) and cloud hosting environments.

---

## 🤖 Android Deployment (Mobile MDM)

To use an Android device as a node in the Swarm Cluster, follow these steps:

### 1. Enable Developer Options
* On your Android device, go to **Settings > About Phone**.
* Tap **Build Number** 7 times until "Developer mode" is active.
* Go to **Settings > System > Developer Options**.
* Enable **USB Debugging** and **Wireless Debugging** (if available).

### 2. Connect to local Swarm Core
* Ensure your smartphone is on the same Wi-Fi as the Swarm Server.
* Use the **Mobile Remote** tab in the Swarm UI to generate a connection token.
* Alternatively, install a PWA (Progressive Web App):
  1. Open Chrome on Android.
  2. Visit `http://your-server-ip:3000`.
  3. Tap **Menu > Add to Home Screen**.

### 3. ADB Control (Advanced)
If you want the Swarm to execute shell commands on the Android device (Remote Control):
* Connect the phone via USB.
* Run `adb devices` on the host machine.
* The Swarm MDM module will now be able to send power, lock, and app commands to the device.

## ☁️ Hosting Deployment (Cloud / VPS)

AI Swarm OS is built for high-scale hosting.

### 1. Docker Cloud (Recommended)
The easiest way to host is via Docker Compose:
```bash
docker compose up -d
```
All persistent data will be stored in `agents.db`. For cloud storage providers, see `storage_spec.md`.

### 2. Cloud Run / GCP Deployment
To deploy to Google Cloud Run:
```bash
gcloud run deploy ai-swarm-os --source . --env-vars-file .env
```

### 3. Linux VPS (Bare Metal)
1. Install Node.js 22.
2. Clone repo.
3. Run `./install.sh`.
4. Setup a systemd service to keep the process alive:
```ini
[Unit]
Description=AI Swarm OS Core
After=network.target

[Service]
Type=simple
User=swarm-user
WorkingDirectory=/opt/ai-swarm-os
ExecStart=/usr/bin/npm start
Restart=always

[Install]
WantedBy=multi-user.target
```
